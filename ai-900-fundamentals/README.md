# AI-900: Azure AI Fundamentals — Portfolio

Hands-on projects built alongside studying for the Microsoft **AI-900: Azure AI Fundamentals** certification. All data is synthetic, generated for Bharani's Retail & Co. (fictional company) — no real employer data is used anywhere in this repo.

## Why this exists

Studying the Microsoft Learn path covers the theory. These folders are the practice half — one small project per exam domain, so the concepts stick before exam day.

## Exam domains covered

| Folder | AI-900 Domain | Weight | Status |
|---|---|---|---|
| [`01-vision`](./01-vision) | Computer vision workloads | 15-20% | 🚧 In progress |
| [`02-nlp-sentiment`](./02-nlp-sentiment) | Natural language processing workloads | 15-20% | ⬜ Not started |
| [`03-conversational-ai`](./03-conversational-ai) | Conversational AI workloads | 15-20% | ⬜ Not started |
| [`04-generative-ai`](./04-generative-ai) | Generative AI concepts | 15-20% | ⬜ Not started |

*(AI workloads/responsible AI and ML principles, ~15-20% and 30-35% of the exam respectively, are covered through the Microsoft Learn modules rather than a standalone project — they're more conceptual and less "buildable.")*

## Tools used

- Azure AI services (free tier where possible — Vision, Language, Bot Service, Azure OpenAI)
- Python / Jupyter notebooks
- Synthetic data generated for Bharani's Retail & Co.

## Each project folder includes

- A short README explaining what Azure service is being demoed and which exam objective it maps to
- A notebook or script showing the working example
- Notes on what tripped me up / what I'd tell past-me before starting
