# Bharani's Retail & Co.

A fictional retail/e-commerce company created as a personal learning project. All data in this repository is synthetic (made-up) and not connected to any real business.

## Purpose

This project is a hands-on sandbox for learning:
- Git and GitHub fundamentals (repositories, commits, branches, pull requests, merge conflicts)
- Python for data cleaning and analysis
- CI/CD basics using GitHub Actions
- Preparation for certifications: **GitHub Foundations**, **GitHub Actions**, AI/Copilot, and Azure fundamentals

## Roadmap

- [x] Phase 1: Generate synthetic inventory data, push to GitHub
- [x] Phase 2: Clean and analyze data with pandas in a Jupyter notebook
- [x] Phase 3: Branching & Pull Requests — added a turnover rate summary via a full branch → PR → merge workflow
- [x] Phase 4: Automated testing with GitHub Actions — CI workflow that runs the notebook end-to-end on every push
- [x] Phase 5: Merge conflicts — deliberately created and resolved one; README/Markdown/.gitignore basics
- [ ] Phase 6: TBD
